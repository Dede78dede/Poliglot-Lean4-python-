## 2. PastaLean Bridge Architecture (Python → Lean 4)

- **Toolchain Pinning**: Pinned to **`leanprover/lean4:v4.31.0-rc2`** as specified in PastaLean's `lean-toolchain`. Cloned at pinned commit `a8f9c12b4e87d10c81d3ef16e53c457d192e42a9`.
- **Dedicated Container**: Implemented `docker/pastalean-runner/Dockerfile` with `python:3.14-slim`, `elan`, and `uv pip install -e '.[server]'`.
  - Security constraints: `--network=none`, `--memory=4g`, `--pids-limit=128`, `--read-only`, tmpfs `/tmp:size=1g`, port 8083 (`pastalean serve`).
  - Documented in `docs/limitations.md`.

### 2.2 Dual Function & Gradual Typing Strategy
- **Dual Function Emission**:
  - `<fn>_provable`: Pure structural/mathematical representation for formal induction.
  - `<fn>_computable`: Executable representation marked `'rn` for compilation into native runtime binaries.
- **Gradual Typing with `PyAny`**:
  - Typed arguments and variables map deterministically to Lean types (`Int`, `String`, `Bool`, `List Int`).
  - Untyped dynamic variables fall back to `PyAny` slots, tracked in diagnostics to prompt type annotations.
- **Hoare Specifications & Auto-Proving**:
  - Synthesizes `⦃ Pre ⦄ <fn>_provable ⦃ Post ⦄` theorems.
  - Attempts automated resolution using PastaLean tactics: `taste?`, `mvcgen`, `omega`, `ring`, `linarith`.

### 2.3 Strict Two-File Rule (`Generated.lean` vs `Proofs.lean`)
- **`Generated.lean`**: Auto-generated by PastaLean, overwritten upon re-translation.
- **`Proofs.lean`**: Human-maintained, never overwritten, imports `Generated`.
- **Fidelity Enforcement**: Enforces `theorem <fn>_fidelity : <fn>_computable = <fn>_provable := by rfl`, preventing translation drift.

## 3. Lungo Bridge Architecture (Lean 4 → 6 Targets)

### 3.1 Upstream Specification Alignment
- **Upstream Origin**: `machinefabric/lungo-rs` (Apache-2.0 License).
- **CLI Version**: `lungo-cli` **v1.86.160** (18 October 2026).
- **Lean Toolchain**: **v4.34.1** (`leanprover/lean4:v4.34.1`).
- **Bridge IR Pipeline**:
  - Compiler output converted to `crates/lungo-bir`.
  - Multi-target codegen via `crates/lungo-codegen` for 6 languages:
    1. **C**: `liblungo` C ABI, `include/lungo.h`, header + C implementation.
    2. **Go**: `gen/go` package with exportable functions.
    3. **Python**: `gen/py` with `lungo-py` support library integration.
    4. **Swift**: `gen/swift` struct and methods.
    5. **TypeScript**: `gen/ts` idiomatic ES module exports.
    6. **Rust**: `gen/rs` with `crates/lungo-runtime` bindings.

### 3.2 Proof-Carrying Packages & SHA-256 Runtime Verification
- **Checked Claims**: Transports formal verification theorems as embedded claims records (`theoremSignature`, `axiomsUsed`, `certificateHash`, `verifiedAt`).
- **Integrity Digest**: Generates SHA-256 runtime digests to ensure uncorrupted runtime package distribution.
- **Multi-Target ZIP Bundle**: Bundles all 6 language sources, checked claims, and `lungo-bundle.json` manifest into a single downloadable ZIP archive.
