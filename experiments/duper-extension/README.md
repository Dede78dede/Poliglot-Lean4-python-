# Duper Superposition Prover Scaffolding & Experimental Sandbox

This directory contains isolated experimental research and Lake project configuration for **Duper**, an automated first-order and higher-order superposition prover for Lean 4 inspired by Isabelle's Metis.

## Status
- **Maturity**: Experimental (leanprover-community)
- **Feature Flag**: `ENABLE_DUPER` (default: `false` in `.env.example` and `docker-compose.yml`)
- **Isolation Policy**: Kept strictly isolated in `experiments/` to prevent contaminating the core Lean 4 Mathlib build tree.

## Architecture
When `ENABLE_DUPER=true` is enabled:
1. `ProofCoordinator` invokes Duper as Tier 1 in the proof automation fallback chain:
   ```
   Duper (Superposition) ──(if fail)──► aesop (Rule Search) ──(if fail)──► Pantograph
   ```
2. Proof candidates generated by `duper` are passed to the Lean 4 kernel verification gate (5-term verification formula) to guarantee no unverified tactics are introduced.
3. If Duper is disabled or encounters a clause explosion, the system falls through gracefully to `aesop` and `Pantograph`.
