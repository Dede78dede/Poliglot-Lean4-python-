### Workspace archive format
- Pattern consolidato: ZIP-based snapshot with `manifest.json`, SHA-256 integrity hashes, path/entry-type validation, manifest version, workspace-contract validation. **Dry-run before restore. Refuse a bad manifest, a newer schema, any checksum mismatch, or a file over its size bound** (pattern `unarr-cli`/`snapshot`).
- **Restore always copies to a staging path** first, verifies, then swaps. Keep the source archive until the destination opens successfully.
- `.polyglot` = ZIP containing: `manifest.json` (schema version, workspace id, created date, appVersion, git ref if any), `vfs/` (project files), `settings/` (polyglot-settings dump as JSON), `flags.json` (feature flag overrides), `audit/` (polyglot-audit-log dump), `bibliography/` (bibliography store), `blueprint/` (DAG), `collaboration/` (Yjs snapshots, optional), `SHA256SUMS` (per-file + archive-level integrity).

## Task WA1 — `.polyglot` Archive Format


Create `src/services/workspace/workspace-archive-format.ts`:


```typescript
export const POLYGLOT_ARCHIVE_VERSION = '1.0.0';


export interface PolyglotManifest {
  readonly schemaVersion: '1.0.0';
  readonly workspaceId: string;
  readonly workspaceName: string;
  readonly createdAt: string;              // ISO 8601
  readonly appVersion: string;             // from package.json
  readonly gitRef?: string;
  readonly files: readonly {
    readonly path: string;                 // relative inside archive
    readonly sha256: string;
    readonly sizeBytes: number;
  }[];
  readonly integrity: {
    readonly algorithm: 'sha256';
    readonly checksumFile: 'SHA256SUMS';
  };
}


export interface PolyglotArchiveLayout {
  readonly manifest: PolyglotManifest;
  readonly sections: {
    readonly vfs: string;                  // 'vfs/'
    readonly settings: string;             // 'settings/polyglot-settings.json'
    readonly flags: string;                // 'flags.json'
    readonly audit: string;                // 'audit/polyglot-audit-log.json'
    readonly bibliography: string;         // 'bibliography/bibliography.json'
    readonly blueprint: string;            // 'blueprint/dag.json'
    readonly collaboration?: string;       // 'collaboration/*.yjs' (optional)
    readonly checksums: string;            // 'SHA256SUMS'
  };
}
```


Requirements:


· Format: ZIP (via fflate, already in bundle).
· SHA256SUMS in sha256sum text format (verifiable with shasum -a 256 -c).
· No path traversal: reject .., leading /, backslashes, null bytes.
· Size bounds: reuse ZIP_LIMITS (Phase 10.9) for individual file and total size.
· Schema version: 1.0.0; refuse archives with a newer schema.
· Deterministic: same workspace → same archive SHA-256 (sort entries, fixed mtime).

· POST /api/v1/workspace/restore — { archivePath, dryRun: boolean, conflictPolicy: 'fail' | 'overwrite' | 'rename' } → { stagedPath?, applied: boolean, conflicts[] }.


Requirements:


· Restore is safe by default: dryRun: true unless explicitly set to false.
