# LP² Adapter Architecture & Caveats (Phase 12, Sprint 12.3)

## 1. Overview
`LP2Adapter` integrates the open-source `lp2` rapid transpiler for bidirectional Python ↔ Lean translation.

## 2. Documented Limitations & Caveats
- **Lossy Round-Trip**: Semantic fidelity is not preserved in round-trip translation.
- **In-Place Mutation**: Python list mutation is silently dropped due to Lean's immutable functional semantics.
- **Termination Proofs**: Integer recursion may require explicit `termination_by` clauses not generated by LP².
- **Unsupported Constructs**: Generators, comprehensions, bytearrays, and f-strings require `@no_transpile`.

## 3. Epistemic Safeguards
- Feature flag `ENABLE_LP2` defaults to `false`.
- Every translation produced by LP² is tagged with `source: 'lp2'` and `requiresFidelityCheck: true`.
- Output must pass `TranslationFidelityGate` before use in any formal verification pipeline.
